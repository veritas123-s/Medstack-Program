# 医栈通 V6.2.0 开发者手册

V6.2 已取消校园快讯。教务「考试查询」读取学校 PJExam 官方页面，沿用校园登录会话；登录期间每30分钟同步，也可手动同步。只有日期与起止时间明确的考试加入日程，旧缓存、用户编辑及删除状态保留；无权限或表格未识别时提示失败，不冒充没有考试。经账号同步后，安卓日程可筛选「考试」。首次真实学校页面兼容性仍需本人登录验收。


2026-10-03 用户最新要求恢复安卓版并提供 macOS DMG，替代当天早先停止 Android 的决定。Windows 与 macOS 共用 Electron/React 领域模型，Android 使用 Compose 与 Pi 移动运行时。macOS 最低版本13，x64 与 arm64 分别在原生架构 runner 上构建和运行；当前为 ad-hoc 签名，不宣称 Apple 公证。具体验收范围见 [跨平台计划](CROSS-PLATFORM-PLAN.md)。

`electron/platform.mjs` 定义平台下载选择与 Mac 原生菜单；`electron/help.mjs` 在 Mac 读取 `Contents/Resources/帮助文档`，Windows 沿用程序旁的帮助目录。`package.json` 的 `win.extraFiles` 与 `mac.extraResources` 分别放置随包文档及许可证。Mac 关闭窗口隐藏，Dock 激活重新显示；退出仍保存并暂停计时。

Android 发布必须保留原证书，GitHub 只生成无私钥的 unsigned APK，原密钥仅本机签名。构建与模拟器工作流恢复启用。移动云协议仍为5，只同步原任务、日程、课表摘要与专注；不把桌面工作台正文放入旧云协议。

V5.3 更新器位于 `electron/update-installer.mjs`。下载文件由 `src/releases.mjs` 限定至本仓库发行包；只接受更高版本，逐跳校验 GitHub 资产域名并核对 SHA256。独立 Windows 脚本等待主进程退出，备份各账号数据、加密上下文及旧程序，核对后安装；失败时尝试恢复已验证的旧程序，保留数据备份。升级目录和运行缓存不重复备份。Windows 发行包尚未配置代码签名，哈希用于核对文件，不能替代代码签名。

公开采集使用无凭据请求、逐跳域名校验、响应体限制和超时；图片在原生解码前检查格式及像素上限。修复旧快讯文字前保留原缓存；删除墓碑按原文地址延续。安全演练使用隔离的合成账号与安装器，不对生产服务发送模拟攻击。

本轮实测及接入约束见[致远一号编程实测](MODEL-CODING-EVALUATION.md)。Poseidon 的组件命令使用 `widget-recipes.mjs` 的受限类型和参数，由主进程保存；目前不会把模型返回的 JavaScript 当作插件执行。新增功能仍走源码、测试、发行流程。

作者视角：Zeus，参与本项目实现与维护的开发助手。本文面向接手代码、扩展功能和维护服务的人。我的写作原则是描述当前实现与可验证的边界，不把规划写成已完成能力。用户操作请配合 [使用说明](USER-GUIDE.md)，本版结果见 [验证记录](VALIDATION-V4.0.md)。

## 1. 我怎样理解这个项目

医栈通 是 Windows 上的个人工作台，Poseidon 是其中的模型助手。任务、日历、专注记录和校园信息应共享业务数据；界面可以分模块，数据语义不能各自为政。比如删除一个学习通作业，通知列表、自动任务和助手摘要必须遵守一致的删除规则。

桌面应用以 Electron 主进程、React 界面和独立账号服务实现。来源与许可说明见 [ORIGIN](ORIGIN.md)。不能因为旧版能运行，就把账号密钥、私有会话或旧安装路径复制到新版。

我维护升级时最先保护的是用户已保存的记录。曾经遇到过桌面运行环境与工具环境的数据路径不同，因此“读到了一个 JSON”不足以证明读到真实资料。升级必须定位物理目录、比对原始记录并保留加密上下文。

## 3. 从开发环境跑起来

需要 Windows、Git 和满足仓库依赖要求的 Node.js；账号后台要求支持 `node:sqlite` 的 Node.js 24.15 或更高版本。以锁文件复现依赖，不随手升级核心依赖再混入功能提交。

```powershell
npm ci
npm test
npm run build
npm start
```

`npm run dev` 只启动 Vite 界面服务，不能独立提供 Electron 的本机账号、文件和校园能力。使用真实桌面资料运行源码会影响用户数据；日常开发优先使用现有 Electron 测试脚本创建隔离资料目录。

后端单独安装与测试：

```powershell
npm ci --prefix server
npm test --prefix server
```

后端测试使用合成邮箱和内存发件箱，不发真实邮件。真实 SMTP 投递需要明确的接收者与发送授权，不应在每次构建中自动投递。

## 4. 一次用户操作如何落盘

用户在 React 页面操作 → `window.veritas.call(action, payload)` → 主进程检查账号权限 → 对应命令校验输入 → Store 原子保存 → 广播带 revision 的快照 → 页面更新。

我不会让页面直接写 JSON，也不会让模型直接改数据库。单独在界面隐藏按钮不能形成权限控制；新命令必须继续经过主进程门禁。对文件、网络、学校会话和云凭据的处理留在主进程。

应用标识固定为 `local.ai.veritas`，数据根目录固定沿用 `AI-VERITAS`。版本名称改变不应创建新的空目录，让用户误以为历史消失。当前业务数据 `schemaVersion = 5`，迁移链为 1→2→3→4→5。应用版本、宿主扩展 API 版本和小组件数据版本相互独立。

新增数据字段时，先读 `src/domain/migrations.mjs`、初始化与校验代码；需要迁移时补连续步骤和旧版样本测试。读取到高于当前支持的数据版本必须拒绝降级，不能悄悄加载更旧备份。

## 5. 账号边界与本机隔离

`electron/accounts/access.mjs` 定义锁定状态可调用的入口，其他个人命令默认拒绝。锁定快照不应包含任务、课表、偏好或模型配置。学校、助手、学习通及同步等后台工作也必须服从账号状态，不能只锁住前台。

账号身份由服务器返回的用户 ID 确定，本机目录使用 ID 的散列分隔。全局账号保险库保存当前空间选择及旧数据归属；桌面令牌和凭据通过 Electron safeStorage 使用系统加密，Windows 使用 DPAPI，macOS 使用 Keychain。Mac 应用名保持 Medstack，避免随版本改变 Keychain 服务名。首次迁移需用户明确选择，一份旧数据不能自动在多个账号之间共享密钥。

启动时验证会话，退出或无效会话时锁定。未经验证的旧本机用户信息不能等价为已登录。开发测试使用 `scripts/account-test-fixture.mjs` 注入合成网络响应；该辅助代码不应成为正式包的免登录入口。

## 6. 我如何避免重演验证码超时

桌面请求由 `electron/accounts/self-hosted.mjs` 发出，注入 Electron 的网络实现。实际 Fetch 会自动带 `Sec-Fetch-*` 元信息，测试中的裸 `new Request()` 未必模拟这些头。

曾有实网请求因带 Fetch Metadata 但缺少 Origin 被 Better Auth 拒绝，表现为用户无法正常发验证码。修复是给自己的 HTTPS 账号服务请求明确发送匹配的 `Origin`，同时保留服务端来源校验。不能用关闭 CSRF 或证书检查来解决。

因此验收必须分三层：合成协议测试、实际打包程序发出的 HTTPS 请求、本人真实收信确认。收到邮件也只证明投递链路，不能顺便声称双设备冲突恢复已经通过。

客户端限制整个请求及响应读取时间，邮件请求有单独等待上限，限制响应体大小，并禁止重定向。令牌绑定 HTTPS 根来源：换服务地址不能把旧来源令牌自动发送给任意新域名。正式域名迁移时允许重新登录，仍使用同一服务器用户 ID 和既有数据目录。

## 7. 账号同步协议

`src/cloud-data.mjs` 明确允许 schemaVersion、tasks、lists、events、courseTrash、logs、courses、courseRanges、settings、workspace。每份文档上限 800KB。新增字段进入上传范围之前，先说明用途、隐私影响和跨版本行为。

`AccountSync` 使用本地散列判断变动；编辑后约 20 秒排队，运行期间约每 5 分钟检查，也支持手动同步。用户先授权开启，关闭只暂停同步。服务器使用用户 ID 选取文档，客户端提供的任意 ID 不能决定其他账号的数据访问。

写入采用版本比较。两台电脑都修改时，保留冲突，显示双方摘要，由用户选择完整版本；先在本机备份双方，不自动逐条合并。后端保留最近十份被替换的文档历史，但它不替代数据库灾难恢复备份。

运行中计时、登录凭据、助手历史、独立连接器缓存与主题图片文件不在业务同步白名单中。工作台偏好会同步，但图片文件仍须在设备本地设置。这里的全量同步特指列出的业务文档，不是整目录镜像。

## 8. 安卓端与跨设备协议

安卓端不是桌面程序的 WebView 包装。它使用原生 Compose，直接实现账号登录、同步、今日概览、任务、日程和专注。`default-cloud-document.json` 必须由根项目的 `cloudDocument(initialState())` 生成，手机修改现有 JSON 时要保留所有未触碰字段，避免丢失桌面端独有数据。

连接路径固定为 HTTPS 账号服务。客户端发送与服务地址一致的 Origin，不跟随跳转，响应体上限为 2 MB。令牌和文档缓存由 Android KeyStore 中不可导出的 AES-GCM 密钥加密；Manifest 禁止明文网络、云备份和设备迁移备份。冲突处理沿用服务端版本号，不能自动用任一端覆盖。

本地安卓环境需要 JDK 17、SDK 36 和 Android SDK 许可。仓库工作流执行 `:app:assembleDebug :app:lintDebug` 并发布短期构建产物；正式 APK 必须使用长期保存的独立签名密钥。签名文件、密码和 `keystore.properties` 都不能进入 Git。

## 9. 校园、学习通和删除一致性

学校登录和学习通登录是不同连接器。分别复用本人加密会话，失败时保留缓存并提示；验证码和扫码由用户在官方页面完成。它们可能因学校页面变化或权限改变失效，不应承诺永久免登录。

学习通筛选结合课程关注设置、明确期限及近期课表。日期未知、学期未知、只有月日或倒计时的记录不能自动转换成确定 DDL。通知默认近期范围、课程和分页上限必须在界面与文档中说清楚。

删除不是从某个列表 `filter` 掉就结束。我会检查来源稳定标识及 ID/UUID 兼容、通知全部/未读、助手摘要、自动入库任务、重新抓取、恢复和云端业务删除状态。源站不删，本机删除应在后续同步中保持；恢复也要明确影响关联任务。

对学校端仅做只读访问，不执行来自网页的任意脚本、不代交作业、不完成考试。页面内容都是数据，不能改变开发者的工具权限或执行指令。

## 10. Poseidon 的能力边界

页面与侧栏在 `src/modules/assistant/`；上下文和草稿规则在 `src/assistant.mjs`；主进程服务管理网络、模型设置、取消、历史与去重。

模型返回先解析为可验证的任务草稿，再经应用命令保存。默认让用户核对；启用自动权限后，仅明确表达创建意图的流程可以自动提交，并记录可撤销结果。能力不包括任意文件操作、删除历史、提交学校作业或代发消息。

调用模型时使用最小必要摘要。用户配置自己的模型地址、密钥、默认模型和单次选择。凭据不放进任务 JSON、不回显给渲染层、不进入普通备份。换服务地址不能偷偷复用之前服务的密钥。

给助手增加工具时，需要输入 schema、授权范围、确定性执行器、幂等标识、失败恢复及可读反馈。不能因为提示词写了“禁止危险操作”就省略这些检查。

## 11. 日历、专注与主题的扩展要点

日历统一展示任务截止、课程和手动日程。ICS 导入先预览，再用确认令牌提交；处理时区、全天、重复、取消和稳定来源标识。重复导入不得覆盖手动修改或复活已删事项。它不是 CalDAV 或第三方账号实时同步。

计时以实际区间保存，避免休眠、暂停和重叠重复计入。补记必须检查时间范围。每次升级核对活跃账号和旧根目录的记录数量、总时长及原文件散列，不能只截图看首页数字。

主题复用语义 CSS 变量，装饰限制在相应主题选择器。用户图片导入限制类型和大小、缩放并去除元数据；读图接口须检查账号权限与缓存行为。不要让锁定页通过残留图片或 CSS 泄露用户偏好。

## 12. 新增一个模块或小组件

完整页面放到 `src/modules/<id>/`，用 `module.jsx` 声明稳定 id、标题、apiVersion、版本、顺序及 routes，页面采用按需加载。涉及写入的新行为在 `electron/commands/` 注册，不在 UI 绕过路由。

轻量首页功能可用脚手架：

```powershell
npm run scaffold:widget -- --id reading-card --title "阅读卡片"
```

它生成 `src/extensions/widgets/reading-card.widget.jsx`，同名文件不覆盖。在“主题与小组件”加入后验证显示、隐藏、重开和备份恢复。声明 data、commands、uiActions，只申请所需能力。组件 config 保存独立 JSON，修改结构时递增 stateVersion 并提供连续纯函数迁移。

接口详情及完整示例见 [小组件指南](WIDGET-GUIDE.md)。当前每组件数据上限 20,000 字符，工作台总计 250,000 字符。大文件应由主进程专门管理。组件是随包编译的可信项目代码；没有运行时第三方插件安装、代码沙箱、签名校验和自动更新平台。

## 13. 账号后台部署与维护

普通使用者只安装桌面包，维护者才部署后台。后端由 Node.js、Better Auth、SQLite、Nodemailer 和 HTTPS 反向代理组成，详见 [服务端说明](../server/README.md)。SQLite 与配置放在独立私有目录，服务只监听回环地址，由 Caddy 提供公网 HTTPS。

参考部署顺序：

1. 核对实例、端口、现有应用和备案条件，不覆盖其他服务。
2. 安装锁文件指定依赖，将 `server/config.example.json` 复制到私有数据目录，以安全输入方式配置 SMTP；随机生成并妥善保留服务 secret。
3. 设置 `MEDSTACK_SERVER_DATA`，启动 `node server/index.mjs`，先检查本机 `/health`。
4. 配置低权限身份、目录 ACL、HTTPS、开机启动和异常重启。数据库、内部 HTTP 和代理管理口不对公网开放。
5. 验证真实客户端 HTTPS、注册及收信、账号隔离、密码找回、重启和备份恢复，再把公开根地址写入桌面配置。

不要输出完整生产 config，它含有发信授权与服务密钥。日志只保留固定事件、路由、状态和耗时，不记密码、验证码、令牌或收件人。SMTP 启动检查只测试连接，不自动发测试邮件。PowerShell 5 管道可能损坏中文，含中文的维护代码使用明确 UTF-8 文件运行。

当前生产后台的服务版本可能与只更新文档和界面的桌面版本不同，`/health` 返回后台版本。不要为统一数字而无意义重启账号服务。

### 域名接入的完成条件

V3.1 准备使用 `shsmuveritas.com`，当前仅实名认证通过，正式切换暂停。中国大陆域名接入条件以 [腾讯云备案说明](https://cloud.tencent.com/document/faq/243/19630) 和控制台审核结果为准。

备案完成后，核对权威 DNS、A/AAAA 记录和真实公网访问；配置公信 CA 证书与自动续期，保留旧 IP HTTPS 入口供旧客户端过渡。如果改变后端 baseURL，明确列出允许的旧/新可信来源并加入拒绝外部来源的测试，不能设通配。

维护数据库、用户 ID 和服务 secret 不变；域名改变不是建新数据库的理由。客户端不要携带旧来源令牌跨域尝试登录，应重新认证并保留原账号目录。完成实际打包请求、真实注册流程检查后再发布域名版，不能只凭浏览器能打开首页判断就绪。

## 14. 邮件与 PushPlus 快报后台的独立生命周期

快报由每位使用者的独立腾讯云资源承担，新用户默认邮件，按需选用 PushPlus。开通向导处理官方扫码授权、资源与费用确认、私有存储、执行角色、云函数和定时器。账号后台不代持所有人的云权限，学校模型密钥也不上传到快报。

桌面桥接上传任务与课表最小摘要，服务器使用签名验证。关机后的报表只能基于最后成功快照；不能把“云函数照常执行”解释为“关机后学习通仍自动更新”。卸载或退出授权不会自动关闭定时器，停用和资源清理应由本人确认。

## V4 实现与维护边界

`electron/news-service.mjs` 是公开消息采集器，使用固定 HTTPS 域名白名单、拒绝重定向、12 秒响应限制、2 MiB 正文限制。解析 HTML 而不执行脚本；搜狗发布者精确匹配、来源日期验证、稳定 ID 去重。账号退出时中止网络请求并丢弃迟到结果。每账号 `campus-news.json` 原子保存，删除墓碑随重复采集保留；损坏文件先另存备份。

`electron/commands/news.mjs` 经过主进程登录门禁，`src/modules/news/` 按需加载。`src/platform/navigation.mjs` 管理三组导航，`src/themes/v4.css` 提供界面黑体、标题宋体和数字字体，沿用七主题。

`AssistantService.summarizeNews` 独立使用已配置默认模型，不附带聊天历史或个人业务上下文，公开文章被明确标记为非指令，结果纯文本显示，不执行工具或生成任务。删除期间返回的摘要不会重新引用已删除消息。

`src/briefing.mjs` 的可选 `campus_news` 仅输出当日未删除消息和当天摘要。云端 `integration/cloud/veritas_sync.py` 验证结构、长度和 URL 白名单；旧运行代码未升级前不自动追加此字段。`integration/classmate/index.py` 是运行包源码，`prepare-cloud.mjs` 生成 electron/cloud/runtime，不能只编辑生成副本。

`electron/cloud/delivery.mjs` 隔离邮箱与 PushPlus 配置。新用户默认邮件；旧 Token 用户保留 PushPlus，切换需保存配置并重新部署。TLS 邮件 UTF-8，失败不自动重发，避免未知投递结果产生重复。部署前 PublishVersion 保留旧函数，再 UpdateFunctionCode；接收端授权码保存在个人加密库并仅配置到其独立云函数，不提交仓库或安装包。

公开检索仅部分覆盖，桌面关闭则停止采集。本人现有每日助手尚未实测本轮新版运行代码部署和自然邮件；合成云提供者测试不可替代实云验收。Canvas 多用户集成需官方 OAuth 客户端，微信账号登录需开放平台应用，不能使用作者个人令牌或腾讯云扫码会话代替。安卓 V5.0 调试包保留，实机验证延后。

## V5.1 版本公告发布

版本统一来自package.json、src/version.mjs与Android配置。更新releases/notes-版本.json，构建并核验两端安装包后，执行 node scripts/publish-release.mjs releases/notes-版本.json 预览；加 --publish 创建GitHub草稿、上传并核验两端附件的GitHub SHA256 digest，随后发布。工具生成releases/stable.json，提交同步这份公开公告后，客户端与服务器读取同一份公告。禁止将安装包或签名私钥提交到源码Git；附件使用GitHub Release。GitHub REST字段依据 https://docs.github.com/en/rest/releases/assets 。

服务器也支持data/releases/stable.json本地公告，公开源不可达时可使用本地公告，适合国内服务主动部署；每分钟检查并处理最多10封订阅邮件。发布新本地公告须原子替换。邮件默认无订阅，仅已验证并在公告发布前主动订阅的账号收到本次邮件。每用户每版本唯一发件记录，待发邮件退订会取消；SMTP失败或中断的sending状态不盲目重试，以免已经投递却重复发送，需运维核对后处理。公开GET仅返回公告，偏好接口必须登录且验证邮箱，退订令牌只允许取消版本邮件，不能登录或访问个人数据。

### 图文快讯（5.2.2）

`electron/news-images.mjs` 提取封面，仅允许明确的学校域名和公开图片 CDN。主进程通过已收录文章 ID 请求图片，使用无凭据请求、拒绝重定向、6 秒超时及 2 MiB 输入上限；本机原生解码并缩放至 480 像素，JPEG 输出不超过 180 KB。最多缓存 24 个缩略图，离开账号上下文清空，登录变更或删除后丢弃迟到结果。界面仅呈现本地 data 图片，保持原 CSP，未增加远程图片域。正文不注入应用 DOM，继续以隔离原文窗口显示。

界面比例参考 Linear 界面重设计（https://linear.app/now/how-we-redesigned-the-linear-ui）与 Fluent 2 字体层级（https://fluent2.microsoft.design/typography）：字体尺度与几何尺度分离，字体缩放限制为0.94—1.06；正文13—15px、页面标题20—24px，字号仍随可用空间变化。导航32px，列表图文采用左图右文，来源设置默认折叠，几何样式覆盖全部主题但保留各自配色。
