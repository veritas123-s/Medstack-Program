# 医栈通 V6.2.0 使用说明

V6.2 已取消校园快讯。教务「考试查询」读取学校 PJExam 官方页面，沿用校园登录会话；登录期间每30分钟同步，也可手动同步。只有日期与起止时间明确的考试加入日程，旧缓存、用户编辑及删除状态保留；无权限或表格未识别时提示失败，不冒充没有考试。经账号同步后，安卓日程可筛选「考试」。首次真实学校页面兼容性仍需本人登录验收。


V6.1 恢复 Android，并提供 Windows 和 macOS 桌面包。V6 医学学习与科研功能见 [工作台指南](WORKHUB-GUIDE.md)。桌面项目与知识记录保存于账号本机，请定期导出完整备份。

适用对象：第一次安装的同学，以及从 AI·VERITAS / 医栈通 旧版升级的使用者。助手名称为 **Poseidon**。

这份说明按当前程序操作编写。界面中的同步时间、覆盖范围和错误提示，比“已经点过同步”更能说明数据是否更新成功。版本验收结果另见 [验证记录](COMPACT-UI.md)。

V5.2.2：任务的专注、编辑和删除位于每行的“⋯”菜单。日历同步与回收站位于日历的“⋯”菜单。首页“小组件”和专注页“补记专注时长”按需展开；主题、配色、组件与模块在独立分类中。

## 1. 安装与第一次使用

### 安装

普通 64 位 Windows 10/11 使用 `Medstack-Setup-6.1.1-x64.exe`，无需安装开发环境。

macOS 13 或以上：在“关于本机”确认芯片，Apple 芯片使用 `Medstack-6.1.1-macOS-arm64.dmg`，Intel 使用 `Medstack-6.1.1-macOS-x64.dmg`。打开 DMG，将 Medstack 拖入 Applications，从“应用程序”启动。菜单栏提供复制、粘贴、缩放和帮助；关闭窗口后可从 Dock 再打开，退出程序使用 ⌘Q。新建任务与搜索快捷键分别为 ⌘N、⌘K。

macOS 包采用 ad-hoc 签名，没有 Apple Developer ID 签名或 Apple 公证。首次打开可能出现系统拦截；仅在确认文件来自本仓库、校验值一致且愿意信任该应用时，按 [Apple 官方说明](https://support.apple.com/en-ie/102445) 在“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭系统整体安全检查。

Android 9 或以上使用 `Medstack-6.1.1-Android.apk`，包名 `com.medstack.app`，与旧正式包使用同一发布证书，可直接覆盖升级。安装权限仅授予实际下载 APK 的应用，安装后可关闭该权限。手机提供任务、同步后的课表与日程、专注、Poseidon 和账号设置；桌面项目与知识库仍只保存于桌面账号本机，不会自动同步到手机。

运行安装程序，选择目录并完成安装。升级前先在旧版托盘菜单选择“退出（保存并暂停计时）”；直接关闭窗口可能只是收起到托盘。升级沿用原数据位置，卸载默认保留数据。不要同时运行新旧两个版本。

这是个人开发项目，Windows 安装程序尚未购买代码签名证书，macOS 签名情况见上文。核对来源后使用，不需要关闭系统安全防护。当前不提供 Linux 或 Windows ARM 原生安装包。

### 注册、登录与旧数据

1. 打开 医栈通，选择“注册账号”，输入自己的邮箱和密码。
2. 点击“发送验证码”，到邮箱收信，回到程序填写验证码并完成验证。密码至少 8 位；验证码有效期 10 分钟。
3. 首次进入账号时，按界面提示选择复制本机旧数据或使用独立空间。只有确认属于自己的旧数据才复制，公用电脑不要导入他人的内容。
4. 登录后进入工作台。未登录时，任务、日程、课表、专注历史、模型配置和个人偏好均不可查看或使用。

旧数据迁移会保留原始文件，已建立的账号空间不会因再次登录而被清空。不同 医栈通 账号拥有独立的本机空间。账号会话在启动时校验；已经通过校验后暂时断网，可以继续本机编辑，云同步须等待联网。退出账号、会话失效或撤销后，个人空间重新锁定。

若发送耗时较长，可停止等待。停止等待不代表撤回已经投递的邮件；收到验证码后仍可继续验证。未收到时先检查垃圾箱及错误提示，再重发，避免反复点击。忘记密码请使用登录页的找回密码入口。

### V5.0 域名状态

`shsmuveritas.com` 已完成域名实名认证，尚未完成 ICP 备案。本版保留原有受信任 HTTPS 账号测试服务，不要求同学手动填写服务器地址。域名正式接入须在备案、证书和实际客户端连接检查通过后完成。域名实名认证通过不表示账号服务已经迁移。

## 2. 十分钟建立自己的工作台

按这个顺序即可开始，不必一次配置所有连接器：

1. 在“任务清单”新建“完成本周生理学复习”，填写准确截止日期、预计投入和所属清单。
2. 到“四象限”把它放入“重要不紧急”；临近截止时重新评估优先级。
3. 在“专注空间”选中该任务，设置本次专注时长并开始，结束后保存记录。
4. 打开“日程日历”，切换月或日视图，核对任务截止时间。
5. 有校园账号时再连接“校园与课表”和学习通；想用 AI 时再填写自己的模型密钥。
6. 最后到“账号与同步”开启全量同步，并在换电脑前确认最近一次同步成功。

## 3. 今日概览与日程日历

今日概览位于三个分类之外，以信息卡片展示时间、今日专注、今日截止、待办任务、今日日程、校园快讯（合并超星通知与公开资讯）。点击卡片箭头进入对应功能；长列表在卡片内滚动，小组件按需展开。今日日程与“日程日历”“校园与课表”使用同一份课程和日程数据。日历支持年、月、日切换与日期跳转；任务显示在截止日期，没有截止日期的任务放在“待安排”。可控制是否显示已完成任务。

点击事项查看或编辑。手动日程用于会议、实验预约和个人安排；需要进入任务清单、四象限或微信 DDL 提醒的事项，应创建有截止时间的任务。手动日程暂不自动变成微信早晚报任务。

课程由校园同步提供。删除日历课程是在 医栈通 中隐藏，后续同步仍遵守隐藏状态，不修改学校服务器；可从日程回收站恢复。日历空白不等于当天没课：先检查课表同步时间、日期范围和失败提示。

### 与其他日历交换文件

1. 在日历打开“导入 / 导出日历”。
2. 导出：选择日期范围和任务截止、校园课程、手动及导入日程等类型，再保存 `.ics` 文件。
3. 备注默认不导出。即使不含备注，文件也可能包含标题、时间和课程地点，分享前先检查。
4. 导入：设定范围，选择 `.ics` 文件，核对预览中的数量、重复项与警告，再确认添加。
5. 导入事项可继续编辑、删除和恢复。重复导入会跳过已有事项，也不会重新恢复已删除的同来源事项。

ICS 是一次文件交换；它不会持续同步 Google、Apple 或其他日历账号的后续修改。日程按北京时间展示；遇到不支持的规则应查看预览警告，不能把预览缺失当成原文件没有事项。

## 4. 任务、清单与四象限

“任务清单”提供待办、今天与逾期、已完成、回收站视图，可按清单筛选。新建任务时写清行动、截止日期与时间、预计投入及优先级；后续可以修改或标记完成。

四象限与清单展示的是同一批任务，不需要重复创建。可以拖动任务更换象限，也可以在编辑中修改：

| 象限         | 判断方法                 | 使用示例               |
| ------------ | ------------------------ | ---------------------- |
| 重要且紧急   | 影响大，期限已近         | 今晚截止的课程作业     |
| 重要不紧急   | 长期收益高，需要提前安排 | 下周考试复习、科研阅读 |
| 紧急不重要   | 期限近，但价值或责任较低 | 可以协调分工的临时事务 |
| 不紧急不重要 | 可以推迟或取消           | 低收益的可选事项       |

在“管理清单”中新建、重命名或删除清单。删除清单时默认保留任务并移入收集箱；如勾选一并删除，任务进入回收站。默认收集箱入口保留。删除任务不会抹去已经保存的专注历史。

## 5. 专注空间与时间记录

### 开始一段专注

选择关联任务，使用番茄或计时功能开始工作。本次番茄可设置 1–180 分钟；固定习惯可在“设置与数据”调整默认专注、短休息、长休息和每日目标。设置变更用于下一段计时。

需要离开时暂停，回来后继续。结束后按界面操作保存，再到“时间记录”核对日期、关联任务和累计时长。暂停、休眠或重叠区间不能用来重复累计投入。

关闭窗口并收起托盘时，程序仍可能计时和提醒；完整退出使用托盘“退出（保存并暂停计时）”。系统关机后，桌面程序不会继续执行新的校园抓取或本地提醒。

### 补记与纠错

漏开计时器时，可以按实际结束时间补记专注时长，范围为 1–1440 分钟。补记内容应与真实工作对应；若提示区间重叠，先核对已有记录，不要为提高统计数字反复添加同一时段。错误记录可以删除，并在对应回收站恢复。

“时间记录”用于查看已保存投入与统计。运行中的计时留在当前设备，保存后的专注记录才进入账号云同步。换电脑前先结束并保存，避免把另一台电脑仍在计时的状态当成已同步记录。

## 6. 校园与课表

进入“校园与课表”，使用自己的学校账号完成官方登录，再同步课表；成绩与教室查询按界面提供的入口使用。连接依赖学校系统、本人权限和可达网络，校外可能需要学校 VPN。

本机加密保存登录信息或会话，以便后续复用。学校要求重新认证、验证码或会话到期时仍需本人完成，不能保证永不过期。换 Windows 用户或新电脑，应重新登录学校系统。

课表有覆盖日期与更新时间。同步失败时先保留缓存，核对学校页面，不要因为缓存为空而认定无课。成绩缓存可清除；删除 医栈通 本地缓存不会删除学校学籍或教务记录。

## 7. 学习通作业与通知

在独立的“超星学习通”标签点击“连接与课程”，再点击学习通登录，在超星官方学生页面使用学习通扫码，完成后返回 医栈通 立即同步。程序运行且个人空间已解锁时定期更新；关机后不会继续从学习通抓取新作业。

默认显示近期有效通知和未完成作业，旧课、已截止、已完成或学期不明事项进入“历史与待确认”。在“管理关注课程”里可以选择自动筛选、始终关注或不关注。自动筛选会参考近期课表与明确日期；学期不明的课程需要你核对后关注。

若启用“学习通未交作业自动加入任务清单”，有明确期限且符合筛选规则的作业可以进入任务系统。只有倒计时、只有月日或缺少年份时会提示估算或待确认，不会冒充精确 DDL。请在超星原页面核实关键截止时间。

通知支持单条删除、批量删除、清理已读和“已删除”恢复。删除状态同时用于全部、未读和助手摘要；删除作业还会把对应本机任务放入回收站。删除只影响 医栈通，不删除超星服务器内容。旧版已导入的历史任务可能仍在清单中，需要在那里单独核对、编辑或删除。

连接器每轮最多读取 30 门所选课程、每门最多 20 页作业、通知最近 5 页，不能保证覆盖超出上限的全部历史。它不代交作业、不完成考试、不代发消息。

## 8. Poseidon：建议与一站式建任务

### 配置自己的模型

点击任意页面顶部的“Poseidon 助手”按钮，再打开连接设置，填写本人 API 的 Base URL、密钥和模型调用名。服务需兼容 OpenAI Chat Completions；Base URL 不要额外拼接 `/chat/completions`。

交大服务地址为 `https://models.sjtu.edu.cn/api/v1`，需要本人授权以及校园网或学校允许的访问方式。其他提供方按其文档填写。更换服务地址时同时填写对应密钥，不会自动借用开发者的额度。

可刷新模型列表、手工填写调用名、设定默认模型，也可对单次对话指定模型或选择自动路由。模型列表读取失败不一定表示聊天接口不可用；先确认调用名，再发一条简单请求测试。费用与额度由你的服务账号承担。

### 从一句话到任务

例如输入：“帮我安排本周五 18 点前完成生理学作业，预计 90 分钟，重要且紧急。”

助手根据可用的个人工作台摘要生成回复和任务草稿。核对标题、日期、时区、清单、优先级与预计投入后再保存。保存成功后，同一份任务会出现在清单、四象限和日历中；有截止信息的任务可被已配置的早晚报读取。

“现在适合做什么”属于建议，应结合课程、截止时间、重要程度和当前可用时间判断。模型可能误解时间或遗漏事项，不能把建议当作学校的正式通知。

### 自动工作流的权限

在“日程与通知”的工作流区域可以启用自动建任务权限。启用后，明确要求“添加 / 创建 / 安排”的助手草稿可以直接保存；默认仍先核对草稿。自动添加记录可以撤销，未完成的新任务进入回收站。

该权限不授予任意电脑控制、删除历史、提交作业或发送消息的能力。模型请求会将所需工作台摘要和对话发送给你选择的模型服务；避免在对话中输入与任务无关的敏感材料。清理助手历史与忘记连接配置是不同操作，按界面提示选择。

## 9. 三种同步分别负责什么

| 功能                       | 目的地与用途                                           | 不会自动做的事                              |
| -------------------------- | ------------------------------------------------------ | ------------------------------------------- |
| 医栈通 账号同步            | 医栈通 账号后台；让自己的多台电脑使用任务、日程等数据  | 不替你登录校园、不共享 API 密钥、不配置微信 |
| 校园 / 学习通同步          | 从本人校园会话读取课表、作业和通知                     | 不修改学校服务器、不保证关机时抓取          |
| 邮件 / PushPlus 早晚报同步 | 本人开通的腾讯云资源；上传任务、课表与可选当天快讯摘要 | 不等同账号全量备份、不自动包含所有手动日程  |

### 账号与跨设备同步

从顶部头像进入“账号与同步”，阅读上传范围并勾选确认，再点“开启全量同步”。支持昵称、清单、任务、日程、课程、已保存专注记录及偏好；这些业务文档里的回收站状态一起保留。

模型密钥、校园登录、微信配置、学习通独立会话与缓存、背景图片文件和运行中的计时不在该同步文档中。新设备需要分别配置连接，不能把“全量”理解为复制 Windows 用户目录。

本机变动会排队上传，也可以点击“立即同步”。换电脑前核对同步状态与时间。若提示“两份修改需要核对”，界面会展示双方摘要；先确认哪份正确，再选择保留这台电脑或云端的完整版本。程序先备份双方，再采用选择结果，另一份独有修改不会自动逐条合并。需要合并时先保存备份并人工整理。

当前单份同步文档上限 800KB。达到限制时先导出备份，联系维护者评估容量，不能通过删除尚未备份的重要记录来盲目消除报错。暂停同步保留本机数据，也不等于删除云端账号。

### 微信早晚报

1. 在“快报与提醒”选择“开通我的早晚报”。
2. 用本人腾讯云账号完成官方扫码登录；可能还需实名认证和开通相关云服务。
3. 默认选择电子邮件，填写自己的收件地址、SMTP 服务器及客户端授权码。仅支持 TLS 465 或 STARTTLS 587；QQ 邮箱使用客户端授权码，不使用登录密码。需要微信时可自行改选 PushPlus 并填写自己的 Token。
4. 阅读资源、费用、摘要上传与每日推送说明，确认后开通。每人使用独立云资源和接收端。
5. 发送测试提醒，实际收到后再点击“已收到”。

默认北京时间 08:00 晨报、21:00 晚报，使用近期截止、逾期与重要任务，以及课程预习和复习信息。关机后云端仍可使用最后一次成功上传的快照；任务快照超过 48 小时、课表超过 7 天会提示核对。因此关机前应确认最新修改已同步。

云资源、请求、流量和推送服务规则以各自账号实际情况为准，不承诺免费或必达。退出临时授权或卸载桌面程序不会自动停止云端定时器。停用时从“我的云资源与后续管理”进入控制台，关闭对应晨报、晚报定时器；删除云资源前确认保存所需数据。

## 10. 安卓端与电脑连接

安卓端通过同一个 医栈通 账号连接电脑端。两端登录后点击同步，即可共享任务、日程、课表摘要和专注记录。手机不需要与电脑处在同一局域网，也不会打开电脑端口或读取电脑文件。

1. 在安卓端登录电脑端使用的 医栈通 邮箱账号；新用户也可直接注册并填写邮箱验证码。
2. “今日”显示临近任务与当天课程，“任务”支持添加、完成和删除，“日程”汇总课程及手工日程。
3. 在“专注”选择 15–90 分钟，结束后保存的记录会进入同一份专注历史。
4. “连接”页显示云端版本和同步状态。两端同时修改造成冲突时，可明确选择云端版本或手机版本。

手机离线修改会先进入由 Android KeyStore 加密的本地缓存，联网后可重试。退出账号后个人页面立即锁定。学校登录会话、模型 API 密钥、腾讯云凭据和 PushPlus token 不上传到安卓端。

## 11. 主题、背景、小组件与侧栏

“主题与小组件”提供七套内置主题：鎏金殿堂、晴日纸间、午夜星图、紫雾花园、轨道时代、千禧漫游、海盐来信。可以随时切换，不会重置任务或计时。

自定义背景支持 20MB 以内的 PNG、JPEG、WebP。选择图片后调整浓度、模糊、位置与布局，再保存配色主题。图片导入会缩放到最长边 2560 像素并去掉原图元数据，文件保存在本机，不经账号同步上传。删除自定义主题后可以恢复；对应图片为恢复保留。

首页小组件可调整显示与布局。随手记便笺用于短记录，可删除并恢复最近一次内容；它不会自动变成微信提醒。当前小组件随应用编译发布，不支持从网上下载任意插件后立即安装。

动画包括弹窗、页面进入、侧栏和按钮反馈，并遵循系统减少动态效果偏好。

八款主题保留清晰的中文界面与数字字体；包括经典医疗主题。标题、正文、按钮和卡片数字随可用空间缩放，并保留最小可读字号。点击侧栏底部“整理侧栏”，可把侧栏收起为图标，或隐藏暂时不用的功能；“今日概览”和“设置”始终保留。隐藏入口不会删除模块数据。

设置页内可直接阅读使用说明与开发者手册，也可重新播放四步新手教程。说明文字集中到教程与手册后，常用页面只保留完成操作所需的提示。

## 13. 常见问题

**邮件一直发送或超时**：先看网络和具体报错；收到邮件后继续验证。未收到再重发。若持续失败，向维护者提供版本、发生时间和错误文字，不提供密码、验证码或 API 密钥。

**登录后看不到原记录**：先确认账号是否正确、首次迁移选择、是否进入另一账号空间以及同步是否冲突。停止反复导入，保留原目录和备份，请维护者核对。升级不应通过清空数据来修复。

**学习通显示旧课或少了一门课**：到“历史与待确认”和“管理关注课程”核对学期与关注设置，再同步。已删除通知在“已删除”中查看；学校原页面仍显示是正常的。

**通知没响或快报没收到**：Windows 通知检查系统通知与勿扰设置；邮件检查垃圾箱、SMTP 配置和定时器。PushPlus 用户检查 Token 和接收状态。发送接口受理不等于已经送达。旧版已配置 PushPlus 的账号保留原渠道，可在向导主动切换。

**另一台电脑没有背景或 API**：这些本机文件和凭据不经账号同步，需单独设置。

**关窗口后程序仍在**：默认收起托盘，完整退出使用托盘菜单。安装升级也应先这样退出。

**想向同学分享**：发送对应架构的安装包即可，两份手册随安装提供。不要附带自己的数据目录、密钥文件、云配置或学校会话。

## 14. 一天的推荐用法

早上核对今日课程、近期任务与最新通知；开始工作前选择一件任务并开专注；下午补充实际变化、纠正截止时间；晚上保存专注、整理回收站与未完成任务，确认同步成功后退出。AI 建议用来减轻整理负担，最终计划由你决定。

## 15. V4 三类入口与校园快讯

侧栏按效率工具、教务信息、校园快讯分组，首页统一日历保持原布局。侧栏入口仍可在设置中隐藏或显示。标题采用华文中宋等宋体，按钮、菜单和表单采用微软雅黑等黑体，计时数字使用等宽数字特性。

在“校园快讯”点击“采集最新消息”。默认在登录且程序运行时首次采集，此后每小时更新；可关闭自动采集。查看选定日期的消息，点击“查看原文”或“查看公开索引”核对来源；删除后进入“已删除”，后续采集不重新显示，可随时恢复。

采集工具覆盖截图列出的 12 个公众号公开搜狗索引、交大综合新闻首页和医学院新闻最近文章。索引名称精确匹配、发布日期验证及重复消息过滤均由程序完成。公开索引有延迟、分页和反爬限制，不能保证全量或不漏；每个来源显示部分覆盖、未能读取或待采集。需要验证码时停止该来源，不绕过验证。漏收的文章可粘贴官方微信 HTTPS 链接补充。

配置好自己的模型 API 后，Poseidon 整理已确认在当天举行的活动；发布日期不会当作活动日期。没有可靠日期的文章留在组织专栏，可在文章卡片中手动确认活动日期。此请求仅提交公开标题、来源、链接与摘要，不提交私人任务、聊天记录、成绩或校园凭据。搜索摘要不代表文章全文，活动报名以官方原文为准。

“组织专栏”按组织查看历史文章，官方原文在隔离阅读窗口中展示原网页排版。正文中的 HTTPS 链接可以点击。网页编码与数字字符实体由采集程序统一解码；非法编码不作为正常中文保存。

对 Poseidon 说“关注上海交通大学公众号”，可以添加组织；准确名称重复添加不会产生副本。这只添加采集来源，不能代替本人在微信中关注，也不能消除公开索引的覆盖限制。

对 Poseidon 说“添加专注小组件”“添加随手记小组件”“添加倒计时小组件，日期 2026-12-20，叫期末考试”或“添加打卡清单小组件”，组件会出现在首页。倒计时与清单可编辑、删除并在组件管理中恢复；已有便笺不会被重复命令覆盖。目前使用预置组件模板，不执行模型生成的任意代码。未配置模型也能使用这些明确命令。

侧栏顶部可一键收起，最简状态保留效率工具、教务信息、校园快讯三个板块；点击板块弹出具体入口，再次展开恢复完整侧栏。

新版云提醒运行程序支持将当天未删除快讯并入早晚报；已有云资源需在向导重新部署以更新函数代码，升级前自动保留旧函数版本。电脑关机后使用最后上传的快照，不会在云端继续采集公众号；没有当日快照会明确提示。本人现有云端渠道尚未进行本轮实际更新及自然邮件送达验证。

教务页新增醒目的学习通连接和 Canvas 官方入口。Canvas 作业自动同步需学校授权 OAuth 应用，V4 暂未开放；微信绑定 医栈通 账号也暂未开放。空教室楼栋同时显示选择的校区，东/西区信息以教务原始名称为准；无可靠映射时不猜测方位。

## V6 医学学习与科研 · 工作台

V6 将项目、任务、知识、日程、专注投入放在同一个桌面工作台中。登录后从侧栏「学习与科研」进入。空白账号不会自动填入示例或虚构科研进度。

### 从一个项目开始

1. 打开「项目管理 → 新建项目」，填写目标、阶段和截止日期。按实际计划添加里程碑。
2. 在项目详情「关联任务」添加任务，或关联已有任务。任务进入原有任务清单和四象限；完成与重开会即时影响项目进度。
3. 点击任务的「专注」进入计时页面。保存的原始专注区间按任务ID计入项目投入，同一任务可以被多个项目引用，各项目投入不能直接相加作为全局总时长。
4. 「项目日程」可以创建或关联日程。创建的日程会出现在原有日历，按北京时间填写起止时间。
5. 项目进度按未删除的关联任务计算。没有任务时显示0/0，不会将其认定为已经完成。里程碑勾选单独保留，项目阶段由用户按实际情况调整。

关联使用稳定ID。修改任务名称或清单不破坏项目关联。解除关联不会删除原任务；项目移入回收站不会删除日程、任务、知识和原始专注记录。已被删除或云同步后不再存在的任务不会计入进度。

### 积累可核对的知识

从项目「写记录」进入时自动关联该项目，也可在知识库独立创建。支持学习笔记、文献阅读、实验记录和会议纪要。正文为空时可插入相应模板；已有正文不会被模板覆盖。

来源栏可以记录 DOI、PMID、网页或原始数据位置。这些内容是人工记录，应用不自动验证引用、下载文件或读取路径。正文以纯文本呈现，粘贴的网页脚本不会执行。标签使用英文逗号分隔。

每次编辑保存一份旧修订，保留最近20版。展开「修订历史」可以恢复旧版，当前正文会成为新的历史记录。恢复后 Poseidon 授权默认关闭，避免恢复旧内容时扩大分享范围。

### 检索与 Poseidon

顶部搜索框或 Ctrl+K 可跨项目、知识、任务和日程搜索。点击结果打开对应记录。单个模块内可搜索名称、正文与标签；「操作记录」在工作台中查看最近3000次工作台操作。

Poseidon 的「附带工作台摘要与已授权知识」打开时，可以获得项目进度摘要。知识正文默认不提供；编辑知识记录并勾选「允许 Poseidon 检索此篇正文」后，模型可按检索词读取相关片段，片段会发送给你配置的模型服务。关闭授权后后续检索立即排除该记录，已经发出的内容无法撤回。关闭助手附带上下文时，本轮不提供工作台工具及旧对话。

助手检索不修改知识。现有任务草稿确认及用户明确启用的自动建任务规则继续生效。笔记中的医学结论与实验结果仍需按原始材料核验。

### 保存、备份与恢复

项目、知识、修订历史与工作台操作记录保存于**当前登录账号的本机目录**。现有云同步仍同步任务、日程和专注等原字段，不同步新工作台，也不上传科研正文。另一台电脑不会自动出现本机项目和知识。

在「设置与数据」导出完整 JSON 备份，可保存全部新旧业务记录。恢复备份会先备份当前内容，再整体替换，请核对账号和备份日期。项目和知识页面均提供回收站，删除后可恢复。

V6首次读取旧数据会留下迁移前文件，原任务、计时区间和主题偏好保留。旧版本无法直接读取V6的本机数据；需要回退时使用升级前完整备份，不要手工修改版本数字。API密钥仍由原有本机加密配置单独保护，不包含在普通业务备份中。
