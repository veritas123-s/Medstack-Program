# 医栈通历代更新日志

从 AI·VERITAS V1、Hades V2–V4 到医栈通 Medstack V5–V6，按版本先后排列。旧名称仅用于对应历史版本。早期版本依据留存的桌面 README、验收记录及构建文件复核；后期版本依据仓库记录和发行说明。下列内容记录各版本当时的变化，已下线的功能也保留在历史中。

## V1 · AI·VERITAS 个人工作台

### V1.0

- 首个 Windows 版，采用 Electron 和 React。参考 MySHSMU 的教务接口、字段与课表逻辑，加入周课表、成绩、课程详情和教室查询，学校网页由本人登录。
- 加入今日概览、清单、任务搜索、到期提醒、子任务、日／周重复任务、四象限拖动及回收站。
- 加入番茄钟、短休息、长休息、正计时和任务关联，支持暂停、继续、补记、时长统计与 CSV 导出。
- 加入系统托盘、单实例、休眠暂停、本地原子保存、自动备份、数据恢复与完整导入导出。Windows 便携包完成验收。

### V1.1

- 以柱廊、石材和黄铜建立纪念性建筑风格。加密保存学校会话，可选保存账号供会话过期时续登。
- 新增「快报与提醒」，汇总备忘、课表、预习复习、四象限重点任务、逾期和临近截止事项，导出快报所需字段。任务支持精确到钟点的截止时间。
- 数据结构从 1 迁移到 2，迁移前保留原文件。云端当时使用部署快照，持续上传在 V1.3 接入。

### V1.2

- 界面拆成模块，支持按需加载、独立领域规则、命令注册及小组件数据迁移。应用数据结构升级至 3。
- 主题可即时切换，首批为鎏金殿堂、晴日纸间和午夜星图。首页卡片可增减、排序、隐藏和调宽，新增「随手记」，主题及组件内容进入完整备份。

### V1.3

- 加入嵌入式 Zeus 助手，连接学校模型。支持拆解任务、生成可编辑草稿、核对后批量加入、去重和取消。
- 任务与课表变动可同步最小快照到私有 COS，加入签名、退避重试和云端回执；早晚报读取最近有效快照。模型与云同步凭据独立加密。
- 修复升级时可能将隔离环境的数据副本误认作日常数据的问题。此后验收先核对真实数据目录，再备份及比对专注记录。

### V1.3.1

- 提供可单独转发的 Windows 离线安装包及卸载入口。使用者可配置自己的 HTTPS 模型服务、密钥和模型名。
- 加入腾讯云官方扫码授权、独立云资源开通与 pushplus 绑定向导。云开通用隔离模拟验收，个人账号的真实开通及自然送达需另行验证。

## V2 · Hades 与 Poseidon

### V2.0

- 应用改名 Hades，助手改名 Poseidon，沿用应用身份和原数据。更新中文排版、圆角与图形。
- 首页集中显示当天与临近安排、未读通知和下一步推荐。学习通通过官方扫码接入作业与通知，支持只读同步、任务去重及自动工作流。
- 可切换默认、自动或手选模型。加入自定义番茄时长与快速补记。

### V2.1

- 加入年、月、日历视图，显示课程与任务截止日期。
- 学习通通知支持单条或批量删除、清理已读及恢复。弹窗、按钮、日历及助手侧栏增加过渡动效，遵循系统减少动态效果设置。

### V2.2

- 首页日程与校园课表合用同一日历数据和组件，新增手动日程及独立清单管理。
- 任务、课程、日程、便笺、清单与自定义主题可删除或恢复。增加本地背景图、配色和主题保存，内置主题扩展到七套，包括紫雾花园、轨道时代和千禧漫游。

### V2.3 → V3.0

- 统一学习通课程相关性及通知筛选。支持自动、关注、不关注，往年、完成、逾期或时间待核对的条目进入历史与待确认。
- 修复同一通知多个平台 ID 导致的删除状态丢失。删除作业可联动对应任务，助手摘要也遵守删除状态；年份待核对的日期不自动写成任务期限。
- 历史目录留有 V2.3 构建；按后续决定，修复并入 V3.0，未单列正式发布。V2.4 是中途拟定编号，最终直接采用 V3.0。

## V3 · 云账号、日历交换与移动端

### V3.0

- 加入云端账号、独立本地账号空间、跨设备同步及冲突前备份。既有 CVM 部署 HTTPS、邮件验证码、低权限服务和每日备份。
- 支持通用 ICS 日历预览、导入去重和导出，保留全天事件与时区。改善侧栏、中文排版、搜索焦点及品牌图形。
- Windows 支持选择安装目录，提供 x64 与 ia32 构建；真正 32 位系统的实机验收在当期仍待完成。

### V3.0.5

- 个人功能统一登录后开放；旧数据和加密配置可由本人选择迁入独立账号，保留原文件。
- 注册验证码增加取消等待、重发及继续验证，完善超时和发信错误反馈。修复 Electron 请求缺少来源标识被拒的问题，随后确认真实注册邮件可收到。

### V3.1

- 增加离线使用说明和开发者手册，登录页和设置页可打开。统一版本标识。
- 私有域名完成实名认证及解析准备；当期因备案状态继续使用原 HTTPS 账号入口。

### V3.2

- 新增原生 Android 伴侣端，支持同账号同步任务、日程、课表摘要和专注记录，显式处理同步冲突。
- 安卓使用系统密钥库保护会话及缓存；服务端增加请求来源校验和安全响应头，移除有风险的解压依赖，并进行隔离攻防验证。
- 桌面调整字体、对比度和可读性；侧栏可收起或隐藏模块，设置整合手册和新手教程。Android 当期交付为测试包，真机验收延后。

## V4 · 效率、教务与校园资讯

### V4.0

- 保留主版面，分出效率工具、教务信息、校园快讯。教室查询同时显示校区与楼栋；学习通连接更醒目，Canvas 提供官方入口。微信登录绑定及 Canvas 自动同步当期暂缓。
- 加入公开来源和公众号索引采集、组织专栏、图文原链、采集覆盖状态及当天活动摘要。修复中文解码和链接跳转，侧栏可收至大分类。
- Poseidon 可一句话关注组织、添加受控小组件，并对学校模型做合成编程评估。推送默认改为邮件，可选 pushplus。公开索引覆盖范围按来源展示。

### V4.1

- 新增「采集最新信息」，筛选最近 24 小时。按原文链接和可靠标题合并转载，保留来源、原链接与删除状态，单列时间待核对项。
- 删除大标题下的冗余描述，首页优先展示待办。设置按类别切换，面板可收起；折叠保留输入及计时。

## V5 · 医栈通品牌与 Pi 助手

### V5.0

- 改名医栈通 Medstack，开屏文案为「医栈事，一站通」，更新应用图标、安装器、托盘和快捷方式。
- 桌面和 Android 接入 Pi Agent Core。助手通过受控工具读取经授权的上下文，生成任务草稿后确认入库。
- Android 提供签名正式 APK，支持 Android 9 起安装。验证签名及模拟器启动。

### V5.1.0

- 加入版本通知中心、启动检查、按版本去重、手动检查及安装包下载，校验官方链接与 SHA256。更新邮件采用自愿订阅。
- 修正 Android 账号请求标识编码。

### V5.1.1

- 精简副标题与说明，首页并排展示待办和日历。设置、外观分组，统计、组件及专注补记按需展开，长列表在页面局部滚动。

### V5.1.2

- 组件、日历、计时器和列表随窗口可用空间调整。左上角图标去框并随主题变色；加入经典医疗主题，主题总数增至八款。

### V5.2.0

- 今日概览独立于分类，以信息卡片展示任务、课程、日程、专注与通知。Poseidon 成为全局按钮，超星独立成页。
- 标题、正文、按钮及卡片数字按可用空间缩放，设定可读下限。

### V5.2.1

- 移除重复通知页，校园信息集中在校园快讯与学习通。首页合并超星通知与公开快讯。
- 快讯增加封面、标题、摘要、来源、日期和搜索；图片不可用时保留文字。收紧字号、侧栏和卡片层级，把推送与自动工作流收到设置。

### V5.2.2

- 移除快讯的「当日活动」标签和「核对活动日期」控件。关于页加入 Medtrix 制作团队、MySHSMU 历史鸣谢及微信联系复制。

### V5.3.0

- 校园快讯直接打开，补充学校官方栏目及公众号原文采集。修复封面、部分编码乱码和删除内容回流，强化跳转、图片解码及超时处理。
- 月历显示课程名及时间，年历显示课程数。Windows 增加一键更新，校验下载并备份数据与程序后安装。
- 进行隔离攻防演练，覆盖恶意跳转、停滞响应与异常图片等场景。见[验收记录](VALIDATION-V5.3.0.md)。

### V5.3.1

- 加入 Medtrix 团队标识，沿用医栈通产品名称和图标。这一阶段一度停止 Android 开发与支持，后续在 V6.1 恢复。

## V6 · 科研工作台、跨平台与教务整合

### V6.0.0

- 新增科研项目、里程碑、任务与日程关联及投入统计。知识库提供学习、文献、实验和会议模板，支持检索、修订恢复与回收站。
- Poseidon 可逐篇读取用户授权的知识，增加全局搜索。科研记录采用本机数据结构 6，云同步保持既有协议。这一版以 Windows 为交付平台。

### V6.0.1

- 调整首页指标、快讯图文列表与侧栏选中状态；分类折叠后仍提示当前位置。统一工作台、项目和知识库的视觉层级。

### V6.0.2

- Windows 更新程序确认安装器启动后才退出；失败时保留应用并提示。
- 快讯增加关键词和主题订阅、分类筛选与屏蔽，记录 SJTU Agent 技术来源并随包保留对应许可。

### V6.1.0

- 恢复 Android，调整底部导航、登录页、字号及深色模式。新增 Intel 与 Apple 芯片版 macOS，支持菜单、快捷键、Dock 和离线帮助。
- 统一桌面表单、对话框、键盘焦点和主题表现，更新按设备平台提供对应下载。

### V6.1.1

- 精简关于页，整理使用说明与开发说明。持续提供 Windows、Android 和双架构 macOS 安装包。

### V6.1.2

- Medtrix 团队标志改为透明背景，去掉白底矩形。

### V6.1.3

- 校园快讯改由服务器统一同步，纳入 12 个既有来源，按小时采集并展示刷新倒计时及覆盖状态。Android 增加快讯搜索、原文和来源状态。公开索引仍可能有延迟和遗漏。

### V6.1.4

- 移除快讯订阅关键词输入与匹配，保留主题订阅、屏蔽、搜索及刷新倒计时。产品默认示例统一采用通用校园内容。

### V6.2.0

- 恢复 Android 持续迭代，加入任务筛选、回收站和 1–180 分钟自定义专注。同步期间保留新编辑，发生冲突由用户选择。
- 取消校园快讯，停止客户端和生产服务器采集，保留历史缓存与学习通内容。检修账号服务、备份、邮件连接和公开接口。
- 接入官方教务考试查询，定时同步时间明确的考试至日历；Android 可筛选已同步考试。

### V6.2.1

- 修复真实考试页「考试课程」表头和月日缺年份的问题。按所选学年、学期确定年份，等待异步表格载入，结果不完整时保留缓存。修正窗口遗留旧版本标题。
- Windows、Android 和双架构 macOS 包已发布。见[验收记录](VALIDATION-V6.2.1.md)。

### V6.2.2

- 课表、任务和已同步考试集中在「日程日历」。原「校园与课表」改成「教务服务」，保留考试、成绩、教室与统一学校连接，移除内嵌的第二份日历。
- 课表、考试、成绩和教室共用教务会话。后台先尝试恢复已有会话，必要时使用本机加密保存的可选账号；并发查询共用一次续登。遇验证码或二次验证时，在「学校连接」处理。
- 超星启动后恢复自己的扫码会话，确认失效才提示重新扫码。Windows 实际发行程序通过合成续登及日历验收，真实学校会话待本机升级后复测。见[验收记录](VALIDATION-V6.2.2.md)。

### V6.2.3

- 桌面后台自行打开教务考试页、选择当前学年和学期、提交查询并等待结果。加载占位或未确认的空表保留原缓存，跨学期保留历史日历安排。
- 启动后自动同步本月课表与本学期考试，每 30 分钟刷新。先复用学校会话，再在必要时自动续登；学校要求人工验证时才提示。

### V6.2.4

- 后台查询学校提供的各学年和学期，合并重复考试，并将近期考试放在前面。部分学期查询失败时仍保留已有结果。
- Windows 新版启动后自动将旧更新安装包移入回收站。维护流程同步清理已确认的前序发行产物及失效快捷方式。

### V6.2.5

- 教室查询改为楼栋看板，按选定日期和时间展示各教室的空闲、占用及用途，缺失数据标为待确认。
- 学习通有确定年份与截止时间的近期作业自动显示在日历，与任务清单中的同源截止去重。
- Windows 主窗口和登录窗口统一使用 Medstack 图标，明确指定任务栏图标资源。
